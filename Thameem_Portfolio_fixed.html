FEATURED PROJECT

AI Voice Agent

“Friday” is a voice-enabled Generative AI assistant built with Python, LiveKit Agents and Google Gemini Realtime. It combines speech recognition, NLP, LLM-based intent understanding, text-to-speech and conversational memory for multilingual real-time conversations.

The code is split into an agent setup (agent.py), the assistant’s instructions and personality (prompt.py) and tool definitions (tool.py). Building it taught me agent development, real-time voice interaction, prompt engineering and tool integration.

Result: 90%+ intent recognition accuracy with latency under 500ms.
